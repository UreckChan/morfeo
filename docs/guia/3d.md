# 3D

## Objetos 3D sobre la escena

`modelo` pone un objeto 3D en su propio lienzo transparente, como cualquier otra capa:

```js
{tipo: 'modelo', forma: 'moneda', ancho: 620, girar3d: [0, 70, 0], tamano: 1.3}
{tipo: 'modelo', forma: 'moneda', cantidad: 40, crecer: true, ancho: 700, alto: 760, rotacion: [18, 0, 0], distancia: 9}
{tipo: 'modelo', src: 'trofeo.glb', ancho: 600, girar3d: [0, 30, 0]}
```

| Campo | Para qué |
|---|---|
| `forma` | Más de 30 incluidas: objetos (`trofeo`, `cohete`, `corazon`…), construcción (`tuberia`, `muro`, `viga`…) y pilas (`moneda`, `lingote`…). Ver [Objetos 2D y 3D](./recursos) |
| `src` | Tu modelo `.glb` en `assets/` (se centra y escala solo) |
| `color`, `metal`, `rugosidad` | Material de las formas incluidas |
| `rotacion` | `[x, y, z]` en grados |
| `girar3d` | `[x, y, z]` en grados por segundo |
| `cantidad` + `crecer` | Pila que va creciendo mientras habla |
| `tamano`, `distancia`, `camaraY` | Encuadre |
| `luz`, `luzAmbiente`, `reflejos` | Iluminación |

## Escenas 3D completas

`escena3d` ocupa todo el cuadro con tu escena de Blender (exportada como `.glb`). La cámara la recorre y salta de toma
en toma en las palabras que indiques:

```js
{say: 'Quitamos la tierra y el agua viaja por el tubo.', capas: [
	{tipo: 'escena3d', src: 'casa.glb', fondo: '#BFE3FF', animacion: true,
		ocultar: [{nodo: 'Tierra', en: 'tierra'}],
		camara: [
			{en: 0, pos: [12, 7, 16], mirar: [0, 0, 0]},
			{en: 'tubo', pos: [3, -1, 6], mirar: [1, -1.5, 1], fov: 35},
		]},
]}
```

| Campo | Para qué |
|---|---|
| `camara` | Tomas `{en, pos: [x, y, z], mirar: [x, y, z], fov}`; la cámara va suave de una a otra |
| `animacion` | `true` reproduce todas las animaciones del archivo, o pon el nombre de un clip (o una lista de nombres) |
| `velocidad` | Velocidad de las animaciones |
| `mostrar`, `ocultar` | `[{nodo, en}]`: piezas por su nombre en Blender (construir paso a paso, quitar una pared) |
| `fondo`, `niebla` | Color de cielo y `[cerca, lejos]` |
| `sol`, `luz`, `luzAmbiente`, `sombras` | Iluminación |

Las coordenadas son las del archivo (no se reescala). Las animaciones van sincronizadas cuadro por cuadro con el video.

::: tip Desde Blender
Archivo → Exportar → glTF 2.0 (.glb). Ponle nombre a las piezas que quieras mostrar u ocultar.
:::
